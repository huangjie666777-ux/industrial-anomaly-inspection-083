上传限制与说明

  • 仅支持 PNG / JPEG，单文件 ≤ 10MB，边长 32–8192 像素。
  • 完整图双线性缩放到 224×224 后按 ImageNet 均值方差归一化（不中心裁剪）。
  • 冻结 ResNet18 提取 layer2/layer3，对齐 14×14 后拼接为 384 维局部描述子。
  • 参考组与校准组不得包含相同图像内容（按缩放后像素哈希判定），重复内容会被拒绝。
  • 记忆库、阈值与预处理信息持久化在服务端，重启后自动恢复；重建失败保留旧库。
  • 热图颜色上限固定为校准阈值的两倍；阈值为 0 时使用校准图最高分，绝不逐图自动拉伸。
